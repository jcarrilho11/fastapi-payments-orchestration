# FastAPI Payment Orchestration Platform

A backend service simulating a payment orchestration API using FastAPI, PostgreSQL, and JWT authentication.

## Implemented Features

- FastAPI + PostgreSQL setup with Docker
- Health check endpoint
- User authentication with JWT
- Register and login endpoints
- Protected routes

## Coming Next
- Transaction submission
- Async processing with Redis

## Running the Application

```bash
   docker-compose up --build
```

Visit http://localhost:8000/docs to test the API.
